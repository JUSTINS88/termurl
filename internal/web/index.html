Shorten links without leaving your terminal.

Try it instantly below, or install the CLI to shorten URLs straight from your shell. No accounts, no tracking bloat.

Use from your CLI

Install the binary once and shorten links directly from your terminal workflow.

01 / Install
$go install github.com/JUSTINS88/termurl@latest
02 / Usage
zsh
$termurl https://github.com/JUSTINS88/termurl -s repo
→ https://termurl.dev/repo

$termurl https://justinsep.me
→ https://termurl.dev/x8k2p

Zero-Friction Auth

Generates a local ~/.termurl.json machine key automatically on first CLI run.

Custom & Random Slugs

Pass -s / --slug for readable aliases or let the server generate a short hash.

Single Binary

Bundles both the CLI client and the serve HTTP daemon in one Go binary.

PostgreSQL Backed

Built on Go net/http, sqlc, and PostgreSQL for sub-millisecond lookups.
